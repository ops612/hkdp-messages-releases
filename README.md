# HKDP Messages: downloads

Installers and the auto-update feed for HKDP Messages, the HKDP WhatsApp inbox
as a desktop app for Windows and Mac. No source code here; the app only opens
the HKDP sign-in page, and staff sign in inside the app.

Latest version:

- Windows: [HKDP-Messages-win-x64.exe](https://github.com/ops612/hkdp-messages-releases/releases/latest)
- Mac (Apple silicon and Intel): [HKDP-Messages-mac-universal.dmg](https://github.com/ops612/hkdp-messages-releases/releases/latest)

Installed apps update themselves from the files of the latest release here.
